## 1) Purpose and Scope

This addendum asks one bounded question: **does MiniMax's public material for M3 (released 2026-06-01, MiniMax's stamp) show the same capability themes the dossier already maps against M2.7 (released 2026-03-18), changed ones, or none?**

- It takes the dossier's claim themes as fixed (`MMAudit-Public.md` §5 crosswalk, §6 CLM-01..06; the summary table in the public note).
- It adds **no** new claims about the author's own work and uses **no** private or personal material. Every fact about the author's work is quoted from the two public documents already in this repository.
- It reads only MiniMax's own publications and reputable coverage, each with URL, access time and grade (§7).
- It draws no legal conclusion and uses no accusatory language in its own voice.
- An empty result is a result: where M3's public material shows nothing for a theme, this addendum says so plainly.

## 3) Method

1. Take the dossier's seven summary themes plus CLM-03 (self-improvement / correction loop) as the fixed list.
2. Take the M2.7 wording for each theme from MiniMax's own M2.7 announcement and model page (the dossier's anchors, §2.2 of `MMAudit-Public.md`).
3. Read M3's public material for the same theme: the announcement, the model page, the API release notes, the Hugging Face model card and GitHub README, the technical report abstract, and the benchmark figure `figures/benchmark.jpeg` from the model card (which carries an M2.7 column).
4. Search the M3 announcement for the theme words themselves and record each as present (quoted) or absent.
5. Classify each theme **Same** (theme carried forward in substance), **Changed** (theme present but reframed, narrowed or re-attributed), or **None** (no public M3 statement on the theme).
6. Grade the source (Verified / Reported / Blocked) and separate Direct evidence from Inference.
7. Do not re-score the dossier. Its 95/100 concerns M2.7 and is untouched here.

## 6) Observed, Inferred, Open

### 6.1 Direct evidence

- **D1.** M3's public material carries no skill or skill-adherence statement and no skill-adherence benchmark row. (§3.1, §4.1)
- **D2.** The OpenClaw framing and MiniMax's MM Claw set do not recur for M3; a third-party Claw-style benchmark (Claw-Eval) appears instead, with an M2.7 column. (§4 row 5, §4.1)
- **D3.** The identity / character theme does not recur for M3. (§3.1, §4 row 6)
- **D4.** In M3's material the agent harness and "Agent Team" are attributed to the MiniMax Code product, described as built on OpenCode and Pi; in M2.7's material harness-building is described as a model capability. (§4 row 2)
- **D5.** The end-to-end coding theme continues, stated through benchmarks with an M2.7 comparison column. (§4 row 7, §4.1)
- **D6.** All primary dossier artifacts predate M3's listing by 79 or more days; the public note predates it by 14 days; this repository's commits by 5 days. (§2.3)

### 6.2 Inference

- **I1.** The dossier's sharpest lane against M2.7 — strict skill adherence as an engineered property (CLM-02/02A) — has no M3 public counterpart. An M3 overlap case cannot rest on it.
- **I2.** The themes that do continue into M3 (end-to-end delivery, agentic iteration, a harness) are the more generic lanes; the dossier's own §15 records the objection "these are generic agent ideas" and answers it, for M2.7, with dated interconnected mechanisms. For M3 that answer is weaker because the mechanism-specific lanes are the ones that dropped out.
- **I3.** Where M3 continues an M2.7 theme, the overlap with the author's work is the M2.7 overlap carried forward, not a new M3 overlap. Nothing in M3's public material matches a dossier mechanism that M2.7's public material did not already match.
- **I4.** The public note's proximity to M3 (14 days) is publication proximity only. See §2.3.

### 6.3 Open questions

- **O1.** MiniMax's Chinese-language WeChat post for M3 (cited by SCMP) was not read; it may carry wording the English announcement lacks. **Blocked** (not fetched).
- **O2.** The technical report body was read only at the abstract; its evaluation sections list agent benchmarks (τ2-bench, TheAgentCompany, SWE-bench) but the report is about the attention architecture. **Blocked** (body not read).
- **O3.** MiniMax Code product documentation was not read. A search excerpt reports "16,000+ specialist skills" in the MiniMax agent ecosystem (**Reported**, unverified). If skills are documented at the product level, the skills theme may live there rather than in the model announcement; this would change row 1 from None to Changed, not to Same, since a skills catalogue is not a skill-adherence claim.
- **O4.** MiniMax has published no M3 training or development timeline.
- **O5.** The dossier's pending third-party exhibits (EX-023..EX-027+) remain pending; this addendum neither adds to nor depends on them.
